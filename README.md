To run the code:
1. Start by setting up a fresh conda environment in your choice of location.
2. Install ipykernel into this environment to use it as the kernel for the notebook.
3. Run the cell to install the requirements.txt to your environment.
4. git clone https://github.com/eleurent/rl-agents.git within the noisy-sensor-handling directory.
5. Run the cell to "!pip install -e ." Ensure that you are doing this from within the newly cloned rl-agents directory.
6. Run the cell for imports
7. Run cells up to the Text cell that says "Baseline Approach" one time.
8. Run the remaining cells to setup each approach and run their related experiments.
